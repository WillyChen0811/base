# F1 截图：/exec/screenshot
在 go/support/macexec.go 加 GET /exec/screenshot?target=screen|xxyi：screencapture -x（xxyi 时只截 XXYI 主窗口：用 osascript/或 CGWindowList 取窗口 id 后 screencapture -l），再 sips -Z 1600 缩小，返回 image/png；临时文件用完删。非 darwin 返回 501。超时 30s。只写实现。
验收：cd go && env -u TMUX -u TMUX_PANE go build ./... && GOOS=darwin GOARCH=arm64 go build ./... && go vet ./support/。不要 git commit。
