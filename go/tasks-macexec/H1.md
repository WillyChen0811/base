# H1 install_app：装上新打的 XXYI.app 并重启（Mac 端，go/macexec + go/support/macexec.go）
背景（D1 调研）：退出 XXYI 会连带停掉 wgtund（本接口所在进程）；重启后协助按 autostart 自动新开，Ubuntu 侧重新读入口即可，不需要恢复旧会话。
要求：
1. 新动作 `install_app`（POST /exec/start {action:"install_app"}）。Mac 端把一段**固定内容**的脚本写到 `~/.xxyi/macexec/<job>.install.sh`（内容在 Go 里写死，不拼接任何外部参数），用 Setpgid 起 `/bin/sh <脚本>`，让它不随 wgtund 退出被杀；接口立即返回 job（State=running，Note「安装中，XXYI 会重启」）。
2. 脚本步骤：确认 `~/xxyi-work/xxyi/mac/build/XXYI.app` 存在且 `codesign --verify --deep --strict` 通过，否则失败退出；`osascript -e 'tell application "XXYI" to quit'`，等 5 秒；`pkill -f "XXYI.app/Contents/MacOS/xxyi"`、`pkill -f "python.* -m xxyi"`、`pkill -9 -x wgtund`；`rm -rf ~/Desktop/XXYI.app && ditto build/XXYI.app ~/Desktop/XXYI.app`；校验桌面副本签名，通过就 `open ~/Desktop/XXYI.app`，否则 `open build/XXYI.app`；每步 echo 到 `<job>.log`；最后由脚本自己把 `<job>.json` 写成 done/failed（写临时文件再 mv）。
3. Runner 启动时把遗留 running 改 failed 的逻辑要**跳过** Note 为「安装中」的 job（它由脚本自己收尾）；超过 10 分钟仍是 running 的才改 failed。
4. 非 darwin 返回 501。
不写测试。验收：cd go && go build ./... && GOOS=darwin GOARCH=arm64 go build ./... && go vet ./macexec/ ./support/。不要 git commit。
